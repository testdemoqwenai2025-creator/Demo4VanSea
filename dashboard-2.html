▸ PLATFORM GLOSSARY · REFERENCE

Platform terms every Cascadia OS user should know

Click any term to expand. Bookmark this page — every term you'll encounter in the dashboard, API docs, and command center is defined here.

AIBizVan360 proprietary · 10-city composite

A composite score (0-100) ranking Cascadia cities by investor readiness. Components: GDP growth, tech employment, VC deployment, startup formation, talent migration. Updated quarterly. Used by VCs for site selection + by economic development agencies for benchmarking.

Where you see it: Dashboard city cards, investor score tab, what-if scenario modeler.
AIBizVan360 data model · JSON Schema + Protobuf

The normalized data model all Cascadia OS services use. Every tender, compliance assessment, bid draft, and provenance anchor conforms to this schema. API responses are Sovereign Schema-compliant. The .proto files are in services/tenders-ingestor/proto/.

Where you see it: API responses, command center data, export formats.
SHA-256 + Polygon blockchain · FIPS 180-4

Every claim in the platform carries a SHA-256 hash linking it to its source document. Monthly Merkle root published to Polygon blockchain — making the audit trail tamper-evident forever. Survives any future change of administration or platform ownership.

Where you see it: Command Center Provenance tab, compliance matrix, bid draft footnotes.
services/compliance-reasoner/ · 6 assessors

Composite 0-100% score from 6 assessors: USMCA, Indigenous, CCA, NAICS, Geography, Prevailing Wage. ≥60% = BID. 40-60% = REVIEW. <40% = GATHER_MORE_INFO. Drives the gauge in Command Center.

Where you see it: Command Center gauge, government.html tender cards.
AIBizVan360 benchmark · monthly

Composite monthly index (0-100) tracking Cascadia innovation velocity vs Bay Area, NYC, Toronto, Austin. 5 components: VC deployment (30%), patents (25%), startup formation (20%), talent migration (15%), IPO count (10%). See cascadia-innovation-index.html for full methodology + chart.

Where you see it: Referenced in weekly brief, economics page, this dashboard's AI outlook section.
UNDRIP Article 32 · E.O. 14112

Indigenous consent framework. Free (no coercion), Prior (before action), Informed (full scope), Consent (right to withhold). Required for any project on ceded/traditional territory. Cascadia OS data sovereignty protocol is FPIC-native.

Where you see it: Environment-agency page, sovereignty assessment tool, compliance matrix.
Pro: 1,000 req/day · Enterprise: unlimited

Free tier: no API access. Pro tier: 1,000 requests/day (REST + GraphQL). Enterprise: unlimited. Rate limit headers included in every response: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset. Burst tolerance: 10 req/sec.

Where you see it: API responses, plan comparison table, usage analyzer.
Mi'kmaq epistemology · popularized by Albert Marshall

Western science + Indigenous knowledge sit side-by-side as equal epistemologies. Neither subsumes the other. Cascadia OS presents both with equal weight in the provenance chain — Principle 4 of data sovereignty.

Where you see it: Environment-agency page, sovereignty assessment, compliance matrix.
services/bid-drafter/ · vLLM + fine-tuned corpus

Auto-generates bid response drafts from your profile + tender requirements. Pro tier: 10 drafts/month. Enterprise: unlimited. Uses a fine-tuned LLM deployed on vLLM (self-hosted, no data leaves the platform). Every draft carries provenance footnotes.

Where you see it: Command Center Review tab, plan comparison table.
AIBizVan360 · Mondays 6am PT · free

Monday-morning email digest: top 5 Cascadia economic data releases (BEA, BLS, StatsCan, Crunchbase, founder panel) with 1-paragraph interpretation per release. ~5 min read. Subscribe at cascadia-weekly-brief.html. CC-BY 4.0 licensed — citable in research.

Where you see it: Referenced in CII page, economics page, this dashboard's news ticker.
