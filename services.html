1 The Wedge's 4 Go Services

The Cascadia OS wedge is built on 4 production-bound Go services, all committed to the private AISeaVanBiz4 repo. Together they implement the first 4 states of the LangGraph bid-drafting state machine: [tender_ingested] → [compliance_assessed] → [bid_drafted].

3 Pipeline Architecture

The 4 services form a pipeline: tenders are ingested → compliance is assessed → bids are drafted — all via an in-memory event bus.

tenders-ingestor

Ingests SAM.gov + BC Bid + WA Commerce + OR Buys → publishes tender.published

→

compliance-reasoner

Consumes tender.published → runs USMCA + Indigenous + CCA assessors → publishes compliance.assessment.completed

→

bid-drafter

Consumes compliance.assessment.completed → drafts bid with provenance footnotes → publishes bid.draft_generated

The pipeline binary wires all 3 services together via a shared InMemoryBus. Single CLI command: ./pipeline --output summary runs the full pipeline end-to-end. See the Pipeline Demo for the actual output.

9 LLM-Based Bid Drafting (Y2)

The Y1 bid-drafter uses a Go text/template engine (formulaic but always available). The Y2 upgrade replaces this with a fine-tuned Qwen 2.5 72B model served via vLLM:

🤖

LLMDrafter (Go)

services/bid-drafter/internal/drafter/llm.go — calls local vLLM endpoint (OpenAI-compatible /v1/chat/completions). Falls back to TemplateDrafter when LLM is unavailable. Temperature 0.3 (low for legal/compliance writing).

📚

Fine-Tuning Corpus

services/bid-drafter/fine-tuning-corpus/ — 5 sources (template bids + user edits + winning bids + regulatory text + Indigenous engagement). Y1 target ~1,250 examples. SFT + LoRA rank 64 on 1× H100.

⚡

vLLM Deployment

services/bid-drafter/vllm-deployment.md — full deployment guide. vllm serve Qwen/Qwen2.5-72B-Instruct --port 8000 --enable-lora. K8s YAML + systemd unit. ~$20/month. 3-tier fallback: Qwen → Claude → Template.

Full design documented in docs/architecture/17-llm-bid-drafting.md.
