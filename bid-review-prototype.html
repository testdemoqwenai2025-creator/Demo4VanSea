1 bid_ready_for_submission — Interactive Prototype

This is the 5th state in the LangGraph bid-drafting state machine. The bid-drafter service generated the draft (state 4); here the user reviews it, makes inline edits, and clicks Submit — triggering the irreversible bid_submitted state.

⚠️ State machine governance

bid_submitted is irreversible. The user has 3 checkpoints: (1) compliance review, (2) bid draft review, (3) final submission. No state can skip a checkpoint.

4 What Happens on Submit (Production)

  1. The bid content + provenance hash is submitted to the procurement portal API (SAM.gov / BC Bid / WA Commerce / OR Buys)
  2. A bid.submitted event is published on the event bus
  3. If the bid cites an Indigenous-nation partnership, a PartnershipCitation event is published (triggering 5% revenue-share accounting)
  4. The bid's provenance hash is queued for the next monthly Merkle anchor to Polygon blockchain
  5. A confirmation receipt is generated and stored in the bids domain
  6. The state machine transitions to bid_submitted — irreversible
