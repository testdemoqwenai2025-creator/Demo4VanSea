1 The bid_ready_for_submission State

This is the 5th state in the LangGraph bid-drafting state machine. After the bid-drafter service generates the draft (state 4: bid_drafted), the user reviews it here, makes edits, and clicks "Submit" — triggering the irreversible bid_submitted state (state 6).

State machine governance (per docs/architecture/11-data-governance-ethical-framework.md §3.4)

bid_submitted is an irreversible state. The user must explicitly click "Submit" — the AI cannot auto-submit. Once submitted, the bid is sent to the procurement portal + a PartnershipCitation event is published for Indigenous-nation revenue-share accounting.

3 What Happens on "Submit Bid"

Clicking the Submit Bid button triggers the bid_submitted state — an irreversible state per the state machine governance. In production:

  1. The bid is submitted to the procurement portal's API (SAM.gov, BC Bid, etc.)
  2. A bid.submitted event is published on the event bus
  3. If the bid cites an Indigenous-nation partnership, a PartnershipCitation event is published (triggering the 5% revenue-share accounting)
  4. The bid's provenance hash is anchored in the provenance ledger (monthly Merkle root to Polygon)
  5. A confirmation receipt is generated and stored
⚠️ Irreversible state

Once bid_submitted is entered, it cannot be undone. The user has 3 human checkpoints before this point: (1) compliance review, (2) bid draft review, (3) final submission review. The state machine enforces this — no state can skip a human checkpoint.
