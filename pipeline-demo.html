5 How to Reproduce

The pipeline binary is in the private AISeaVanBiz4 repo at services/pipeline/cmd/pipeline/main.go. To run:

cd services/pipeline go build -o /tmp/pipeline ./cmd/pipeline /tmp/pipeline --output summary # visual summary (above) /tmp/pipeline --output bid-markdown # full bid markdown /tmp/pipeline --output json # all events as JSON
