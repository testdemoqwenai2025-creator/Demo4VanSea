Security Policy

How to report a vulnerability, what's in scope, safe harbor, and the Indigenous-nation data sovereignty note.

Responsible disclosureSafe harbor48h ack5-day response

1 Reporting a Vulnerability

The Cascadia OS team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

Please DO NOT file public GitHub issues for security vulnerabilities

Instead, report vulnerabilities via one of these channels:

  1. GitHub Security Advisories (preferred) — navigate to github.com/.../AISeaVanBiz4/security/advisories/new and submit a private advisory. The maintainers are notified immediately.
  2. Email — send to security@aibizvan360.com with [SECURITY] in the subject line. You will receive acknowledgement within 48 hours and a substantive response within 5 business days.

2 Scope

In scopeOut of scope
The AISeaVanBiz4 private source repo and any code that ships from itThe public Demo4VanSea preview repo (it contains only static HTML — find/vuln, no need to report)
GitHub Actions workflows in .github/workflows/Self-hosted runners (we do not use any)
The Sync to Preview GitHub Action — including any way to coerce it into publishing non-HTML content to the public repoThe public preview site served via GitHub Pages (it is read-only static HTML)
Any way to extract the PREVIEW_TOKEN secret or other Actions secretsPerformance, denial-of-service, or scrape-rate issues against public APIs

4 Safe Harbor

We will not pursue legal action against reporters who:

  • Make a good-faith effort to avoid privacy violations, destruction of data, and interruption of services.
  • Do not exfiltrate data, including PII or Indigenous-nation partnership data.
  • Give us reasonable time to remediate before public disclosure.
  • Do not exploit the vulnerability beyond what is necessary to demonstrate it.

5 Indigenous-Nation Data Sovereignty Note

Elevated priority

This repository references partnership data with Indigenous nations (currently the Muckleshoot Indian Tribe; expansion planned). Any vulnerability that would expose consented partnership data to unauthorized parties is treated with elevated priority.

Reporters who identify such exposure are eligible for a discretionary bounty, paid in the form of a contribution to an Indigenous-led technology nonprofit of the reporter's choice (with their consent).

6 Supported Versions

The main branch of AISeaVanBiz4 is the only supported version. The public Demo4VanSea repo is a derived artifact; any security issues in Demo4VanSea originate from AISeaVanBiz4 and must be reported there.

7 Contact

  • Security advisories: github.com/.../AISeaVanBiz4/security/advisories/new
  • General security questions: security@aibizvan360.com
