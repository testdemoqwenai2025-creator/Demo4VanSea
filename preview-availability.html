All non-HTML artifacts (code, .md, .pdf, .json, .js, .png, banners, sector icons) live exclusively in the private AISeaVanBiz4 repository. HTML pages in built-output/ are fully self-contained — every asset is inlined as a base64 data URI or inline <script> block.

4 How the Preview Stays 24/7/365

The preview is served by GitHub Pages from the public Demo4VanSea repo's main branch. GitHub Pages is a globally distributed CDN with hundreds of edge locations. There is no scheduled downtime. There is no maintenance window.

The preview is updated automatically on every push to main on the private AISeaVanBiz4 repo:

StepActionTypical duration
1Push to private main (e.g., a contributor merges a PR that touches built-output/)~0s
2Sync to Preview GitHub Action triggers — runs on a GitHub-hosted runner~30s
3Workflow wipes the public repo working tree (preserving .git/), then copies only the .html files from built-output/ into the public repo root~5s
4Workflow asserts the HTML-only policy — if any non-HTML file ends up in the public tree, the workflow fails (no commit / no push)~1s
5Workflow commits and pushes to the public repo with message Auto-sync HTML-only from AISeaVanBiz4 <timestamp>~3s
6GitHub Pages detects the push and rebuilds the site~30–60s
7CDN edge caches refresh~1min globally
End-to-end worst case~2–3 minutes

5 What Happens During a Regional-Scale Disruption

The Pacific Northwest is the most seismically and climatically volatile region in North America (M9 Cascadia earthquake risk, atmospheric rivers, wildfire smoke). The preview is designed to keep operating during regional-scale disruption:

🌐

GitHub Pages is hosted outside Cascadia

GitHub's primary data centers are not in the Pacific Northwest. A regional Cascadia infrastructure failure does not take the preview down.

📦

The source repo is also on GitHub

The source-of-truth repo is not in Cascadia either. Both the preview and its source survive a regional event.

⚡

CDN edge caches survive origin failures

Even if the origin (GitHub Pages) is unreachable, edge caches continue serving the last-known version for hours.

🔧

Sync runs on GitHub-hosted runners

The sync workflow runs in GitHub's data centers, not on local Cascadia infrastructure.

For everyone, not just Cascadia

The preview will continue to be accessible during a regional Cascadia disruption, even if Cascadia-based users cannot access the internet. The preview is for everyone, not just Cascadia.

6 Legal / Access Policy for Interested Parties

The public preview is provided "as is" for observation by any interested party. There is no NDA to sign, no access request to file, no approval process. The preview is intended to:

  • Investors — evaluate the platform's vision and trajectory without disclosure gating
  • Policymakers — observe the data products and the regional moat
  • Academic researchers — cite the platform's methodology and the CIRS scoring rubric
  • Indigenous-nation partners — observe before formally engaging (the public preview is the starting point for a relationship, not a substitute for one)
  • General public — observe the use of public taxpayer-funded data (EPA, USGS, NOAA, iNaturalist, etc.) aggregated for the Cascadia corridor

The public preview may be cited, screenshotted, and shared freely. Attribution to "Cascadia OS — https://testdemoqwenai2025-creator.github.io/Demo4VanSea/" is appreciated but not required.
